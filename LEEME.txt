¿QUE ES ESTO?

Este conjunto de archivos generará un sistema Tekams Jump completo
con login screen, autenticación de usuarios y control de permisos.

ARCHIVOS INCLUIDOS:

1. generar_tekams_completo.py

   - Genera el archivo HTML final

2. GENERAR_TEKAMS.bat
   - Archivo ejecutable que corre el script Python automáticamente
   - Simplifica el proceso de generación

3. LEEME.txt
   - Este archivo con instrucciones
